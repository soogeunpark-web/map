STEP 1 · QUERY

지도용 데이터는 두 가지 모양이면 충분합니다

칸을 칠하는 지도  H3로 집계

SELECT
  city_nm,
  h3_res_9,
  COUNT(*)  AS demand,
  COUNTIF(order_result_cd = 'success') AS success_cnt,
  COUNTIF(order_result_cd = 'failure') AS failure_cnt
FROM `<주문 테이블>`
WHERE /* 기간 · 조건 */
GROUP BY 1, 2

→ 한 행 = 육각형 한 칸

선을 잇는 지도  두 지점 좌표

SELECT
  order_no,
  ST_Y(vendor_loc) AS pickup_lat,
  ST_X(vendor_loc) AS pickup_lng,
  ST_Y(order_loc)  AS drop_lat,
  ST_X(order_loc)  AS drop_lng,
  order_result_cd,  vendor_nm
FROM `<주문 테이블>`
WHERE /* 존 · 기간 */

→ 한 행 = 주문 하나 = 선 하나

STEP 2 · 3 · PROMPT

실제로 이렇게 요청했어요

처음 요청CSV 파일을 열어서 지도에 h3_res_9 컬럼 기준으로 취소율 시각화를 만들어줘. 취소율은 failure_cnt / demand × 100에 %를 붙이면 돼. 칸을 클릭하면 demand, success_cnt, failure_cnt, 취소율이 가볍게 보였으면 좋겠어. 왼쪽 상단에 city_nm 체크박스로 원하는 city만 보여주고 싶어.
다듬기지도가 검은색인데 시각화하기 좋은 지도로 변경해줘
문제 해결회사라서 그런지 계속 "API KEY REQUIRED"라고 나오네. 방법이 없을까?
참고 파일예전에 작업했던 파일인데 여기서 지도 참고할 수 있어? (+ index.html 첨부)
